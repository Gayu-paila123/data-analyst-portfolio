Customer Shopping Behavior Analysis using SQL

Project Overview

This project analyzes customer shopping behavior using SQL and Python. The analysis explores customer spending, product performance, category revenue, and monthly sales trends.

Tools Used

- Python
- SQL
- SQLite
- Google Colab
- Pandas

Dataset

A sample dataset containing 8 customer records, including:

- Customer ID
- Age and Gender
- Product and Category
- Quantity and Price
- Order Date

Key Business Insights

- Total Revenue: ₹68,400
- Total Customers: 8
- Total Products Sold: 15
- Average Order Value: ₹8,550
- Highest Order Value: ₹50,000
- Best Revenue Month: February 2026 (₹55,400)
- Top Revenue Product: Laptop (₹50,000)
- Laptop contributed 73.10% of total revenue.

Business Recommendations

- Promote high-performing products.
- Explore opportunities to increase Beauty category sales.
- Monitor monthly revenue trends.
- Encourage repeat purchases.
- Diversify revenue across more products.

Skills Demonstrated

SQL Queries, GROUP BY, HAVING, Subqueries, CASE WHEN, Aggregate Functions, Window Functions, Data Analysis and Business Insights.
