E-commerce Customer Segmentation

Project Overview

An E-commerce Customer Segmentation project using RFM (Recency, Frequency, Monetary) analysis to understand customer purchasing behaviour and identify valuable customer groups.

Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Plotly
- Google Colab

Dataset

A sample dataset containing 10 customers, their order frequency, total spending, and days since their last purchase.

Analysis Performed

- Data inspection and cleaning checks
- Customer spending analysis
- High-value customer identification
- Customer ranking
- RFM scoring
- Customer segmentation
- Revenue analysis by segment
- Interactive dashboard creation

Customer Segments

- VIP Customers
- Loyal Customers
- Regular Customers
- At-Risk Customers

Key Metrics

- Total Customers: 10
- Total Customer Spending: ₹143,500
- Average Customer Spending: ₹14,350

Visualizations

- Customer Segmentation Analysis
- Customer Spending by Segment
- Customer Purchase Activity
- Revenue Contribution by Customer Segment
- Interactive Customer Segmentation Dashboard

Skills Demonstrated

- Data Analysis

- RFM Analysis
- Customer Segmentation
- Data Visualization
- Business Insights
