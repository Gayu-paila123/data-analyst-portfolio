Sales Performance Dashboard

Project Overview

An interactive sales performance dashboard built using Python, Pandas, and Plotly to analyze sales revenue across products, regions, and categories.

Tools Used

- Python
- Pandas
- Plotly
- Google Colab

Key Performance Metrics

- Total Revenue: ₹146,000
- Total Orders: 10
- Products Sold: 20
- Average Order Value: ₹14,600

Key Business Insights

- Laptop generated the highest product revenue: ₹100,000.
- North was the highest-performing region: ₹107,500.
- Electronics contributed ₹136,500 in revenue.
- Accessories contributed ₹9,500 in revenue.
